## The entry

`main.ts` (Node 22) writes one text to `/output/entry.txt` — 307 characters, a short thank-you to the AI judge reading it. The program runs in a sandbox with no network and is fully deterministic: the same text, byte for byte, on every run.

## Run it

```sh
node main.ts
```

It writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR`, or to `./output/` when that is not set.
